# ChIP-Seq Analysis Project – COMPEPIWS 2024

This project is part of the Computational Epigenomics workshop (COMPEPIWS 2024) at Saarland University, conducted under the supervision of Prof. Jörn Walter and Jun-Prof. Fabian Müller.

##  Objective
To analyze ChIP-Seq data using the `nf-core/chipseq` pipeline and perform chromatin segmentation with ChromHMM, followed by exploratory analysis using IGV and R.

## Main Tools & Steps
- **Nextflow `nf-core/chipseq`** for data processing
- **FastQC, MultiQC, deepTools2** for quality control
- **IGV** for signal and peak visualization
- **ChromHMM** for segmentation (5–15 state models)
- **R/ggplot2** for summarizing chromatin states

## Folder Descriptions
- `results/`: Final report and HTML summaries

##  Outcomes
- Clear distinction of histone mark enrichment patterns
- Segmentation into interpretable chromatin states
- Visual evidence of differences between kidney/liver stages
